```text
=== 设计规范说明 (DESIGN SPECIFICATION) ===
1. 目标陈述:
   参考 claude.ai 官网的视觉语言，为 AI 任务编排控制台构建亮色/暗色双主题系统。风格克制、有质感、信息层次清晰，
   适合工程师长时间使用的专业工具界面。

2. 审美方向:
   奢华/精致风 (Luxury/refined) × 极致极简主义 (Brutally minimal)
   —— 大量留白、精细排版、柔和过渡，拒绝视觉噪音。
   参照 claude.ai 的「暖米白 + 深棕」色系。

3. 色彩调色板:

   【亮色模式 Light】
   - 背景主色    #F5F0E8  (暖米白，claude 标志性底色)
   - 背景次色    #EDEAE2  (浅沙色，侧边栏/面板)
   - 边框/分割   #D9D4C8  (暖灰)
   - 主强调色    #D97757  (claude 标志性赭橙色)
   - 次强调色    #8B6F5E  (深暖棕)
   - 文字主色    #1A1612  (近黑暖棕)
   - 文字次色    #7A6E65  (中性暖灰)
   - 成功        #3D8B6E  (暖绿)
   - 危险        #C0392B  (沉红)
   - 警告        #C07A2B  (琥珀)

   【暗色模式 Dark】
   - 背景主色    #1C1917  (深暖棕黑)
   - 背景次色    #242120  (次深棕)
   - 边框/分割   #3A3532  (暗棕灰)
   - 主强调色    #E8896A  (亮赭橙，暗色下更亮)
   - 次强调色    #A08070  (暖棕灰)
   - 文字主色    #F0EBE3  (暖白)
   - 文字次色    #8A7E76  (暗暖灰)
   - 成功        #5AAF8A  (亮暖绿)
   - 危险        #E05A4A  (亮沉红)
   - 警告        #E09A4A  (亮琥珀)

4. 排版字体:
   - 标题/导航:  'Tiempos Text' / 降级 'Georgia' (衬线，claude 官网风格)
   - 正文/标签:  'Söhne' / 降级 'DM Sans' (几何无衬线)
   - 代码/数据:  'Berkeley Mono' / 降级 'JetBrains Mono'

5. 布局策略:
   - 左侧 220px 宽导航栏（展示项目名+分组菜单），非图标栏
   - 内容区顶部固定 48px 面包屑/操作栏
   - 列表+详情采用「主从分栏」，列表区 360px，详情区自适应
   - 大量留白，行间距宽松，无重阴影，用细边框区分层级
   - 状态标签使用小圆点 + 文字，无色块背景

6. 图标方案:
   Lucide Icons（线条风格，与 claude.ai 一致）
```

### PAGE 1 — 总览仪表盘 `/dashboard`

**接入接口**
| 接口 | 用途 |
|------|------|
| `GET /tasks/stats` | 任务统计数字 |
| `GET /tasks?limit=5` | 最近任务列表 |
| `GET /sessions?limit=5` | 最近会话列表 |
| `GET /acp/runs?limit=5` | 最近 runs |
| `WS :8701` | 实时事件流（task_updated / run_event） |

**布局**
```
┌──┬─────────────────────────────────────────────────┐
│  │  [STATS ROW]  queued | submitted | completed | failed  │
│  │  (4格非对称宽度，斜切角数字卡)                │
│N │                │
│A │  ┌──────────────────────┬──────────────────────┐       │
│V │  │  最近任务 (3列宽)     │  实时事件流 (2列宽)  │       │
│  │  │  状态色块条列表       │  WS 滚动日志         │       │
│  │  │                荧光绿闪烁光标       │       │
│  │  └──────────────────────┴──────────────────────┘       │
│  │  [最近会话 横向滚动条带]                                │
└──┴─────────────────────────────────────────────────┘
```

### PAGE 2 — 任务管理 `/tasks`

**接入接口**
| 接口 | 用途 |
|------|------|
| `GET /tasks` | 列表（支持状态筛选） |
| `POST /tasks` | 创建任务（右侧面板表单） |
| `GET /tasks/:id` | 点击行后加载详情 |
| `POST /tasks/:id/input` | 详情区续聊输入 |
| `POST /tasks/:id/terminate` | 详情区终止按钮 |
| `WS :8701` → `task_updated` | 实时状态刷新 |

**布局**
```
┌──┬──────────────────┬──────────────────────────────┐
│  │ [筛选栏]          │  TASK DETAIL │
│  │ queued ▼  [+NEW] │  ─────────────────────────── │
│N │                  │  ID / 状态时间线 (横向步骤条) │
│A │ ████ task-001    │                │
│V │ ████ task-002    │  [消息历史 滚动区]            │
│  │ ████ task-003    │                               │
│  │ ████ task-004    │  ┌─────────────────────────┐ │
│  │ ...│  │ > 续聊输入框│ │
│  │                  │  └─────────────────────────┘ │
│  │ 固定 320px        │  [TERMINATE] 按钮(硬红)      │
└──┴──────────────────┴──────────────────────────────┘
```

### PAGE 3 — 会话管理 `/sessions`

**接入接口**
| 接口 | 用途 |
|------|------|
| `GET /sessions` | 会话列表 |
| `POST /sessions` | 创建会话 |
| `GET /sessions/:id` | 会话元信息 |
| `GET /sessions/:id/history` | 历史消息加载 |
| `POST /sessions/:id/input` | 发送消息 |
| `POST /sessions/:id/dispatch` | dispatch 操作 |
| `WS :8701` → `session_output` | 实时输出追加 |

**布局**（类 IM，但工业风）
```
┌──┬────────────────┬────────────────────────────────┐
│  │ [+ NEW SESSION]│  session-abc  [codex]  ACTIVE   │
│  │ ─────────────  │  ─────────────────────────────  │
│N │ ● session-abc  │                │
│A │   codex        │  [消息气泡流]                   │
│V │ ● session-def  │  左：AI输出（荧光绿文字）        │
│  │   claude       │  右：用户输入（琥珀橙文字）      │
│  │ ● session-ghi  │                                 │
│  │   gemini       │  ─────────────────────────────  │
│  │                │  [DISPATCH ▼]  [输入框]  [SEND] │
│  │ 固定 260px      │                                 │
└──┴────────────────┴────────────────────────────────┘
```

### PAGE 4 — ACP 运行管理 `/acp`

**接入接口**
| 接口 | 用途 |
|------|------|
| `GET /acp/runs` | runs 列表 |
| `POST /acp/runs` | 创建 run |
| `GET /acp/runs/:id` | run 详情 |
| `POST /acp/runs/:id/input` | 发送输入 |
| `POST /acp/runs/:id/pause` | 暂停 |
| `POST /acp/runs/:id/resume` | 恢复 |
| `POST /acp/runs/:id/terminate` | 终止 |
| `GET /acp/sessions/:sessionKey` | 侧边抽屉查询 |
| `WS :8701` → `run_event` | 实时事件 |

**布局**
```
┌──┬──────────────────────────────────────────────────┐
│  │ [+ NEW RUN]  筛选: ALL / RUNNING / PAUSED         │
│  │ ──────────────────────────────────────────────── │
│N │ run-001  submitted  codex   [▐▐] [▶] [■]         │
│A │ run-002  paused     claude  [▐▐] [▶] [■]         │
│V │ run-003  completed  gemini       ──   ──          │
│  │ ──────────────────────────────────────────────── │
│  │ [展开行] → 内联展开事件流 + 输入框（非跳转）      │
│  │                │
│  │ [SESSION KEY 查询] → 右侧抽屉滑出 │
└──┴──────────────────────────────────────────────────┘
```

### PAGE 5 — 实时监控 `/monitor`

**接入接口**
| 接口 | 用途 |
|------|------|
| `WS :8701` → 全部事件 | 主日志流 |
| `POST /bridge/feishu/events` | 飞书事件（只读展示入站） |
| `POST /bridge/openclaw/channel/events` | OpenClaw 频道事件 |
| `POST /callbacks/openclaw` | 回调入站记录 |

**布局**
```
┌──┬──────────────────────────────────────────────────┐
│  │ ● WS CONNECTED   [PAUSE]  [CLEAR]                │
│  │ Tab: [ALL] [task_updated] [run_event] [session]  │
│  │ ──────────────────────────────────────────────── │
│N │ 04:01:09  task_updated   task-001  → completed   │
│A │ 04:01:08  run_event      run-002   paused        │
│V │ 04:01:07  session_output sess-abc  "output..."   │
│  │ ...  (虚拟滚动，荧光绿等宽字体，新行从底部推入)  │
│  │ ──────────────────────────────────────────────── │
│  │ Tab: [飞书桥接] [OpenClaw桥接] [Callbacks]       │
│  │ 各 Tab 内为独立日志列表                           │
└──┴──────────────────────────────────────────────────┘
```

### PAGE 6 — 系统配置 `/settings`

**接入接口**
| 接口 | 用途 |
|------|------|
| （运行时状态为本地配置读取） | 展示 codex/claude/gemini/openclaw 配置 |
| `POST /bridge/threads/:id/control` | 线程 pause/resume/terminate |
| `GET /callbacks/openclaw` (若有) | 回调历史记录 |

**布局**
```
┌──┬──────────────────────────────────────────────────┐
│  │ Section: RUNTIMES                                │
│  │ ┌──────────┬──────────┬──────────┬────────────┐ │
│N │ │ CODEX    │ CLAUDE   │ GEMINI   │ OPENCLAW   │ │
│A │ │ ● ACTIVE │ ● ACTIVE │ ○ IDLE   │ ● ACTIVE   │ │
│V │ │ [配置项] │ [配置项] │ [配置项] │ [配置项]   │ │
│  │ └──────────┴──────────┴──────────┴────────────┘ │
│  │ Section: THREAD CONTROL│
│  │ thread-id 输入 → [PAUSE] [RESUME] [TERMINATE]   │
│  │ Section: CALLBACK LOG│
│  │ 入站 openclaw 回调记录表格                        │
└──┴──────────────────────────────────────────────────┘
```
